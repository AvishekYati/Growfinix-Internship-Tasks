# Growfinix Task 3 — Customer Segmentation Using Unsupervised Learning

## 1. Project Overview

This project implements an end-to-end customer segmentation system using unsupervised machine learning.

The objective is to discover hidden groups of customers from transaction-level retail data without predefined customer segment labels.

The project transforms raw transaction data into customer-level behavioral features, applies K-Means and DBSCAN clustering, evaluates the clustering results, visualizes the customer segments in 3D using PCA and Plotly, and converts the discovered segments into actionable marketing strategies.

---

## 2. Business Problem

Businesses often have large amounts of customer transaction data but do not have clearly defined customer segments.

This project aims to identify groups of customers with similar purchasing behavior and answer questions such as:

* Which customers are high-value?
* Which customers are inactive or at risk?
* Which customers purchase frequently but spend less?
* Which customers show growth potential?
* How can marketing campaigns be targeted differently for different customer groups?

---

## 3. Task Objective

The Growfinix Task 3 requirement is to apply unsupervised learning to unlabeled customer data, discover hidden customer segments, and visualize the clusters in 3D space for targeted marketing analysis.

This implementation uses:

* K-Means clustering
* DBSCAN clustering
* PCA
* Plotly 3D visualization

---

## 4. Dataset

The project uses the Online Retail transaction dataset.

The raw transaction data contains fields such as:

* InvoiceNo
* StockCode
* Description
* Quantity
* InvoiceDate
* UnitPrice
* CustomerID
* Country

The transaction-level data is converted into customer-level behavioral features before clustering.

---

## 5. Feature Engineering

Customer behavior is represented using RFM-style analysis and additional purchasing features.

### Recency

Number of days since the customer's most recent purchase.

Lower recency indicates more recent activity.

### Frequency

Number of unique invoices/orders associated with the customer.

Higher frequency generally indicates stronger engagement.

### Monetary

Total revenue generated by the customer.

Higher monetary value indicates greater customer value.

### Additional Features

* Total Units Purchased
* Unique Products Purchased
* Average Order Value
* Average Quantity per Order

These features provide a broader representation of customer purchasing behavior.

---

## 6. Data Preprocessing

The project performs the following preprocessing steps:

1. Load the transaction dataset.
2. Validate required columns.
3. Convert dates and numerical columns to the correct data types.
4. Remove records without CustomerID.
5. Remove cancellation transactions.
6. Remove invalid or non-positive quantities.
7. Remove invalid or non-positive prices.
8. Calculate transaction revenue.
9. Aggregate transaction data at customer level.
10. Transform highly skewed numerical features.
11. Standardize model features using StandardScaler.

---

## 7. Machine Learning Methods

### K-Means Clustering

K-Means is used to group customers with similar behavioral characteristics.

Different values of K are tested and evaluated using:

* Elbow Method
* Silhouette Score

The best-performing cluster count is selected based on the clustering evaluation results.

### DBSCAN

DBSCAN is implemented as a density-based alternative to K-Means.

DBSCAN can:

* discover dense groups of customers
* identify unusual customer behavior
* label potential outliers/noise as `-1`

---

## 8. Model Evaluation

### Elbow Method

The Elbow Method analyzes K-Means inertia for different cluster counts.

The point where additional clusters provide diminishing improvement is considered when selecting a suitable K.

### Silhouette Score

Silhouette Score evaluates how well-separated the discovered clusters are.

Higher values generally indicate better-defined clustering.

### DBSCAN Evaluation

DBSCAN is evaluated using:

* number of clusters
* number of noise customers
* silhouette score where applicable
* k-distance analysis for parameter selection

---

## 9. 3D Visualization

PCA is used only for visualization.

The standardized feature space is reduced to three principal components:

* PC1
* PC2
* PC3

Plotly is then used to create interactive 3D visualizations of:

* K-Means customer clusters
* DBSCAN customer clusters

The clustering model itself uses the full standardized feature space.

---

## 10. Business Segmentation

The discovered clusters are interpreted using customer behavior rather than the arbitrary cluster number.

Possible business-oriented segments include:

### High-Value Loyal

Customers with strong purchase frequency, high spending and recent activity.

### At-Risk / Inactive

Customers whose last purchase was relatively long ago and who show lower recent engagement.

### Frequent Low-Spend

Customers who purchase frequently but generate comparatively lower revenue per order or in total.

### New / Promising

Customers with relatively recent activity but lower purchase frequency.

### Regular / Growth Potential

Customers showing moderate purchasing behavior who may respond to personalized offers and loyalty campaigns.

The actual final segment labels depend on the observed clustering results.

The customer segments can be used to support targeted marketing decisions.

| Customer Segment           | Recommended Strategy                                                            |
