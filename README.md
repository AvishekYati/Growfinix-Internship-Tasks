## Completed Tasks

### Task 1 - Automated Image/Video Metadata Extraction

A computer vision pipeline that analyzes digital images and video frames and automatically extracts useful metadata.

Key capabilities include:

- Object detection
- Object confidence scoring
- Bounding box detection
- Dominant color extraction
- RGB color analysis
- HEX color representation
- Lighting analysis
- Contrast analysis
- Image quality analysis
- Video frame analysis
- Automatic metadata generation
- Annotated output generation

Technology:

- Python
- OpenCV
- PyTorch
- YOLO
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Pillow
- Jupyter Notebook

Project:

`Task-1-Automated-Media-Metadata`
