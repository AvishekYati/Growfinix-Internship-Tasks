# Growfinix Tour Enquiry LLM Fine-Tuning

## Project Overview

This project fine-tunes a lightweight open-source language model
using LoRA to create a tourism customer-service assistant.

## Objective

The objective is to train the model to respond to customer
tour enquiries using a consistent professional company tone.

## Technologies

- Python
- PyTorch
- Hugging Face Transformers
- Hugging Face Datasets
- PEFT
- LoRA

## Features

- Customer enquiry handling
- Tourism recommendations
- Budget-related enquiries
- Family/honeymoon/group travel enquiries
- Cancellation enquiries
- Date-change enquiries
- Professional customer-service tone
- Interactive chatbot

## Methodology

1. Dataset creation
2. Data preprocessing
3. Train-validation split
4. Tokenization
5. Base LLM loading
6. LoRA configuration
7. Fine-tuning
8. Evaluation
9. Interactive inference

## Results

Document training loss, evaluation loss,
test cases and example responses.

Install requirements and open:

Run the notebook cells sequentially.
